# Security Policy

## Supported Versions

NP-LANG is currently in an experimental prototype stage. Security updates will be applied to the latest commit on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in NP-LANG, please do NOT report it as a public GitHub issue.

Instead, please send an email with details, reproduction steps, and potential impact to:

📧 **victorejiki@gmail.com**

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or a minimal proof of concept (.np source file or AST).
3. The affected component (Playground, Language Core, or Native Compiler).

We will review your report, acknowledge receipt within 48 hours, and coordinate a fix and advisory disclosure.
